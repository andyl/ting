# Ting

Static site built with [Astral](https://hexdocs.pm/astral/) and
[Volt](https://hexdocs.pm/volt/).

Static HTML - public website at [andyl.github.io/ting](https://andyl.github.io/ting).

## Development

```sh
mix deps.get
mix astral.dev
```

Build the deployable site in `dist/` with:

```sh
mix astral.build
```
